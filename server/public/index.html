Why ToolHub?

A self-hosted alternative to VS Code Marketplace, designed for enterprise teams who need full control over their development tools.

📦

Multi-Type Resources

VS Code extensions (.vsix), Copilot skills, custom agents, and instruction files — all in one platform.

⚡

One-Command Deploy

Simple Node.js setup with zero external dependencies. Start serving tools to your team in seconds.

🔧

Native VS Code Integration

Browse, install, and update tools directly from VS Code sidebar. Automatic update notifications.

📊

Analytics & Ratings

Track downloads, user ratings with distribution charts, and monitor resource popularity across your team.

Auto Discovery

Getting Started

Three steps to your own developer tool registry.

  • 1

    Start the Server

    Install dependencies and start the server locally.

    npm install && npm run dev
  • 2

    Publish Resources

    Upload extensions, skills, agents via the API or CLI.

    curl -X POST /api/publish -F "file=@resource.vsix"
  • 3

    Install the Extension

    Add the ToolHub VS Code extension, configure your registry URL, and start browsing.

    "toolhub.registries": [{ "name": "Team", "url": "http://your-server:3000" }]
